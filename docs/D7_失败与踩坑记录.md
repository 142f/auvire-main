# D7 失败与踩坑记录（本轮实时追加）

> 目的：把"看起来顺利"的部分剔除，只留下真正花过时间的东西。每条都写**现象 → 根因 → 处理**。

## A. 环境 / 工具链

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| A1 | 远端命令回显 `PWD=E:Projectauvire-main`，`git status` 报 "not a git repository" | 本地 pwsh 在**双引号字符串**里先展开了 `$PWD`/`$?`，把本地路径塞进了远端命令 | 远端脚本一律**写文件再执行**（`.tmp/cmd.sh` + `node .tmp/rex.js --file`），或在 pwsh 里用单引号 |
| A2 | 多行命令在某个 `echo` 之后整段丢失输出 | 同上（引号/转义）+ 命令字符串被截断 | 改为脚本文件 + SFTP 上传（`.tmp/push.js`），不再用内联长命令 |
| A3 | `rw_*` 工具全部拒绝执行（"this session is LOCAL"） | dsh-remote 要求会话工作区就是远端镜像；本会话是本地工作区 | 直接用 ssh2 写 `rex.js`（执行）/ `push.js`（SFTP）两个小工具，密码认证 |
| A4 | `nvidia-smi` 长期显示 5040 MiB 已占用、利用率 0% | 已退出的进程残留的 GPU 上下文记账（PID 已不存在） | 以 `ps` + 利用率采样判断真实占用；不要据此认为 GPU 忙 |
| A5 | 复制项目目录到 `auvire-main-maqs` 后 DataLoader 全 None | 清单里的路径是**相对路径** `data/LAV-DF_emb_avhubert/...`，副本没有 `data/` | `ln -s /3240608030/auvire-main/data data`（只读复用） |
| A6 | `write_meta.py` 找不到 `utils/lavdf_train.json.full.json` | 备份文件名与拼接规则不一致 | 统一为 `utils/lavdf_{split}.full.json` |
| A7 | `set -e` 让烟雾测试在第一条失败命令处静默退出，看不到 `exit=$?` | `set -e` 与 `cmd; echo $?` 冲突 | 用 `cmd \|\| true` 再取尾部日志 |

## B. 复现相关（重要）

| # | 现象 | 根因 | 处理 |
|---|---|---|---|
| B1 | **基线 checkpoint 不存在**，无法直接复跑 3k 诊断 | `config.py: delete_ckpt=True` + 训练结束删除 `.pth` | R1 用 `AUVIRE_KEEP_CKPT=1` 重训；今后的臂一律保留权重 |
| B2 | 远端 ckpt 只剩官方权重 + 两个结果 json，`ckpt/2x2/*` 已消失 | 同上 + 目录重组 | 以"重训 + meta.json 固化 md5"的方式重建可追溯性，不再依赖口头记忆 |
| B3 | 本仓库 **无 git 历史**（远端是部署拷贝，不是 clone） | 部署方式 | 本地为唯一版本库；每次同步后用 `source_md5`（meta.json）证明远端代码 = 本地 commit |
| B4 | 单变量保证：加质量支路会不会改变基线初始化？ | `nn.Module` 构造顺序决定 RNG 消耗 | 质量头**最后构造**，且提供 `AUVIRE_QUALITY=0`；实测 state_dict/前向/损失**哈希逐位一致**（`.tmp/equiv_check.py`，见 D6） |
| B5 | `losses.py` 里 `inputs[:, :, 1:]` 在 4 通道下把质量通道当成偏移，触发 `offsets>=0` 断言 | 硬编码 3 通道契约 | 改为 `inputs[:, :, 1:3]`（三通道时逐位等价） |
