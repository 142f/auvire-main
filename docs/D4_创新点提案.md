## 1. 主创新：MAQS — Metric-Aligned Quality Scoring（度量对齐质量打分）

### 1.1 一句话主张
给 AuViRe 增加**第三条打分支路**，用"评测器自己计算的区间 IoU"作软目标训练它，解码时用该质量分重排提案，使"排在前面的提案"与"IoU 高的提案"一致。

### 1.2 与基线的机制差异（不是超参差异）
| | AuViRe 基线 | MAQS |
|---|---|---|
| 分数来源 | 单一 `sigmoid(cls_logit)`，语义是"该帧是伪造的概率" | `s = p^α · q^(1-α)`，其中 `q = sigmoid(quality_logit)`，语义是"以该帧为中心发出的区间与 GT 的 IoU" |
| 监督信号 | 帧级 0/1（focal） | 质量支路用**软目标 IoU**（连续、依赖当前回归输出，detach） |
| 与指标的关系 | 间接（只有通过"帧级真伪"才与 IoU 相关） | 直接（目标函数里出现的就是评测用的那个 IoU） |
| 尺度差异 | 四个尺度共享同一 logit 分布，粗层系统性偏移 | 每个尺度有独立质量头，天然学到级间校准（吸收 P3） |

### 1.3 因果链（为什么能解决问题）
1. 分类头的目标与"段内位置"无关 → 同一段内各帧 logit 近似相等（时序平滑）；
2. AP 是**全局池化**排序（metrics.py:102），近失提案（0.8≤IoU<0.95）以几乎相同的分数插在真 TP 之间；
3. 要让 AP@0.95 涨，必须让"IoU>0.95 的那条提案"严格排在"同段近失提案"之前；
4. 质量支路的软目标 IoU 在段内呈**单峰**（段中央可达 IoU 高、边界处因偏移被截断而低），于是 q 天然携带"这条提案有多准"的信息；
5. 乘到 p 上后，TP 与近失 FP 的相对次序被 q 拉开 → 高召回区精度上升 → AP@0.95 上升；低阈值区 TP/FP 差异本就巨大，q 的扰动被 p 的主导性吸收（故 @0.5/@0.75 不应回退，这是**可检验的预测**）。

### 1.4 新增参数与算力
- 新增 **+1,116,676 参数**（12,101,516 → 13,218,192，**+9.23%**；占总量 8.45%），全部在 `Model.quality`（每尺度一个与分类头同构的 HeadModule）。
- 算力：前向多一个头的 conv（约 +7% FLOPs 量级），实测 epoch 时间以 R2 的 meta.json 为准。
- **默认开启**（`config.py` 的 `model.quality.enabled=True`、`criterion.composition` 含 `quality`），不可整体移除而保持论文配置（关掉 = 基线臂，正是消融项）。

### 1.5 预期失败模式
1. **q 退化成 p 的副本**：若回归已经很好，IoU 软目标在几乎所有正样本上≈1，q 变成第二个分类器 → 增益为 0。判据：q 与真实 IoU 的 Spearman ρ<0.3。
2. **@0.5/@0.75 回退**：q 的噪声在低阈值区把真 TP 压下去。判据：@0.5 或 @0.75 回退 >0.3pp（验收线）。
3. **训练不稳**：软目标依赖当前预测（非平稳），早期噪声大。缓解：β=2 的 |t−p|^β 权重 + 只在正样本上归一化（与 focal 同分母）。
4. **增益只来自"用了偏移量"这一几何事实**：见 Q3 的启发式对照，若启发式能复现 80% 增益，则新颖性降级。

### 1.6 消融怎么拆
| 臂 | 变量 | 回答什么 |
|---|---|---|
| A 基线 | `AUVIRE_QUALITY=0` | 参照 |
| B 完整 MAQS | 默认 | 总增益 |
| B1 | 同一 checkpoint，`AUVIRE_Q_ALPHA=1.0`（融合关） | 增益是否来自**解码融合**而非"多训了一个头" |
| B2 | 同一 checkpoint，α∈{0.9, 0.8, 0.5, 0.2} | 融合强度曲线，选点规则固定为"dev 上选，test 上只报一次" |
| C 启发式对照 | 基线 checkpoint + 用**预测偏移本身**构造的重打分（如 `s·exp(-k·|o_l+o_r|` 或 `s/(1+o_l+o_r)`） | 排除"只是几何"的更简单解释 |
| D 硬标签对照（可选，需重训） | 质量目标换成 0/1 | 排除"多一个分支"本身的作用 |

### 1.7 论文里的 3 句 novelty statement
1. We show that the residual gap of reconstruction-based temporal deepfake localization at AP@0.95 is a **ranking** gap, not a boundary gap: 89.3% of ground-truth segments already have a proposal with IoU>0.95, yet AP@0.95 is 83.2.
2. We introduce **metric-aligned quality scoring**, a third scoring pathway supervised by the very interval IoU the evaluator uses, which turns the score from a frame authenticity probability into an interval-quality-aware ranking signal.
3. Unlike set-prediction localizers (UMMAFormer) and video-level detectors (BA-TFD), the mechanism adds no query/matching machinery and no new input modality: it re-uses AuViRe's dense anchor-free heads and changes only what the score *means*.

## 2. 备选（Backup）：MAQS-R — 近失对排序项

- **一句话**：在质量支路上加一个**同视频内 pairwise 排序损失**：对每个 GT 段，取"最佳正提案"（IoU≥0.95）与"最难的近失提案"（0.8≤IoU<0.95），要求 `q_pos − q_near ≥ m`。
- **机制差异**：QFL 学的是"绝对质量回归"，MAQS-R 学的是"相对次序"，直接对齐 AP 的排序语义。
- **为什么能解决**：240 个近失段是排序损失的主要来源（D3），显式对比项把梯度集中在最难分开的样本上。
- **新增参数**：0（复用质量支路）；算力 +O(1) 采样。
- **失败模式**：近失样本在训练早期不存在（回归还没收敛）→ 需要 warmup；可能过拟合到 0.8–0.95 区间而牺牲 @0.5。
- **消融**：B vs B+MAQS-R，看 @0.95 的增量与 @0.5 的回退。
- **novelty**：把"评测的排序语义"显式写进损失，而不是靠软目标隐式传导。

## 3. 三问必答

**Q1 换数据集（LAV-DF ↔ AV-Deepfake1M）还成立吗？**
成立的前提是"排序损失仍占主导"。质量目标由各数据集自己的标签算出，机制与段长分布无关；但 AV-Deepfake1M 段更长、标注更粗（LLM 生成），软目标 IoU 的分布会整体右移（更容易接近 1），此时 q 的动态范围变小、增益可能衰减。**这是可检验的**：若在 AV-Deepfake1M 上 q 的方差 <0.02，则预期增益 <0.5pp。
（本轮限制：远端没有 AV-Deepfake1M 特征，见 D7；泛化用 LAV-DF 的第二设定代替。）

**Q2 换 backbone / 换特征还成立吗？**
质量头只吃 encoder 输出的 `[B,d,T]`，与特征来源解耦；换 backbone 只改变特征的判别力，不改变"分数需要携带 IoU"这一逻辑。代价是每个尺度多一个头（+9.2% 参数在 d=128 下；若 d 翻倍则 +18%，此时可共享一个跨尺度的轻量头作降本方案）。
真正的风险在**分辨率**：若换成时间分辨率更低的特征（如 25fps→12.5fps），短段 IoU 的可行域变小，q 的监督信号变稀。

**Q3 有没有更简单的对照能解释掉这个增益？**
有三个，必须全跑（都在 §1.6）：
1. **α=1.0（融合关）**：同一模型、同一权重，只关解码融合 → 若仍涨，说明是"多训一个头带来的正则/多任务效应"，不是打分机制；
2. **偏移启发式重打分**（零训练）：只用预测偏移构造分数 → 若复现大部分增益，说明增益来自"偏移量与 IoU 的几何关系"这一平凡事实；
3. **按级常数校准**（已做，+0.72pp）：若 MAQS 的增益不超过它，则创新点退化为"手调常数的学习版"。
MAQS 必须**同时**满足：α=0 时增益显著、启发式显著弱于学习式、超过 +0.72pp。

## 4. 与 SOTA 的三句话差异（验收 [5]）

1. **vs AuViRe**：AuViRe 的分数是帧级真实性概率 σ(cls)，回归头只影响框的位置、不影响排序；MAQS 让"框有多准"进入排序，且用评测器自己的 IoU 作监督。证据上，AuViRe 在 LAV-DF 上 AP@0.5 98.91 → AP@0.95 46.52（官方），而 AR@5 已 92.16 —— 召回不缺、排序缺（D1 §G2）。
2. **vs UMMAFormer**：UMMAFormer 用 Transformer 查询 + 逐位置回归 + PCA-FPN，排序仍由分类分支承担，且**必须为每个数据集/模态组合单独训一个 ckpt**（"universal"是集成意义）；MAQS 不引入查询/匹配，保留 AuViRe 的稠密无锚头，只改分数的语义与监督。
3. **vs BA-TFD / BA-TFD+**（全称 **Boundary Aware Temporal Forgery Detection**，D1 已核实）：它们是**视频级检测器**（LAV-DF 上 AP@0.95 仅 0.24 / 4.44，AR@100 67.03 / 81.62），没有可排序的区间集合；MAQS 面向区间级 TFL 的高分位排序，二者不在同一评测轴上。

> 新颖性风险（自曝）："分类分 × 定位质量"在 TAL/TAL 系里已有隐式形态（ActionFormer 系的一致性加权、GFL 的 QFL）。本工作的**差异化**必须落在三点上，写作时不能含糊：
> (a) 软目标**由评测器自身的区间 IoU 定义**（与指标同口径，D2 差异 #9/#10 说明这是本任务特有的坑）；
> (b) **每个时间尺度一个质量头**，把"粗层分数被系统性高估"这一实测现象（+0.72pp 的手调常数，D3-P3）变成可学习量；
> (c) 提供**oracle 排序上限**（把分数换成真实 IoU 后的 AP@0.95）作为该方法族的理论上界，并用**质量通道置换**对照排除"分布外信息"。
