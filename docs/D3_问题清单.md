> 证据来源：远端 `/3240608030/auvire-main/results/diag/C_all_3000.json`（C_cont 基线，test 前 3000 条视频 / 2,552 个 GT 段，soft-NMS 之后、AP/AR 之前统计），

> 所有数字都可由此二文件复算（D6）。

## 0. 先把天花板钉死

| 量 | 值 | 含义 |
|---|---|---|
| GT 段总数（3k 子集） | 2,552 | AP 的 recall 分母 |
| 至少存在一个 IoU>0.95 提案的段 | **2,280（89.34%）** | "完美排序"下 AP@0.95 的上限 |
| 实际 AP@0.95 | 83.15 | 距上限 **6.19pp** |
| IoU>0.5 / >0.75 的可达率 | 99.96% / 99.33% | 低阈值早就饱和，不是瓶颈 |

| 段长分布 | <10 帧 648，10–20 帧 1101，20–40 帧 803 | 大量极短段 |

**所以 AP@0.95 的 16.85pp 缺口 = 6.19pp 排序损失 + 10.66pp 不可达（其中 240 段是 0.8≤IoU<0.95 的近失）。**

## 1. 候选问题（6 项全写）

### P1 打分不含定位质量（主问题）
- **现象**：最高 IoU 阈值上的失败不是"框不对"，而是"对的那个框排不到前面"。
- **证据**：89.34% 的段存在 IoU>0.95 的提案（可达），实际 AP 只有 83.15；AP@0.5/0.75 已 98.7/95.8，缺口全部集中在 @0.95；解码分数 = `sigmoid(cls_logit)`（eval.py:300），回归头输出的偏移**不参与打分**。
- **根因假设**：分类头是帧级二分类，段内部各帧的 logit 几乎相同（时序平滑），于是"段内靠中心的提案"与"边界完全正确的提案"分数几乎并列；而 AP 是**全局池化**排序（metrics.py:102），近失提案以同等分数插在真 TP 之间，直接压低高召回区的精度。
- **可证伪判据**：(a) 若把排序换成"按真实 IoU 排序"（oracle 排序），AP@0.95 仍 <85 → 不是排序问题（可用诊断脚本零成本验证）；(b) 若训练出的质量头与真实 IoU 的 Spearman ρ < 0.3 → 分支没学到东西，假设不成立。
- **预期增益上限**：+6.19pp（到 89.34 为止）；现实预期 +1.5~3pp。
- **实现成本**：代码 4 文件 ≈ 120 行；单臂训练 3.3h（与基线同预算）。

### P2 提案覆盖不足（10.66%）
- **现象**：272/2552 段无论怎么排序都拿不到 IoU>0.95 的提案。
- **证据**：`unreachable_095=272`，`near_miss_08_095=240`；648 段短于 10 帧，理论上要求起止合计误差 <0.25 帧。
- **根因假设**：提案中心只能落在整数帧网格上（stride=1 的最细层），短段的 IoU 对边界误差呈 1/L 放大。
- **可证伪判据**：若在 240 个近失段上把边界误差强制置零能把它们的 IoU 推到 >0.95 —— 已知**能**（这正是 0.8–0.95 的定义），所以这条**不是**可证伪的失败，而是**已被量化的小空间**：即使全救回，上限 +9.4pp 但需要亚帧回归，而 93% 的段误差已 <0.5 帧。
- **预期增益上限**：+2~4pp（且与 P1 不叠加）。
- **实现成本**：两阶段边界精炼，1–2 人日 + 2×3.3h。
- **结论**：**排除**（见 §2）。

### P3 分数跨尺度/跨视频不可比
- **现象**：粗尺度（stride 2/4）的提案分数系统性偏高或偏低。
- **证据**：仅按级乘一个常数（`AUVIRE_LEVEL_SCALE=1,1,0.9,0.8`）就 +0.72pp；只保留 stride=1 两级 +0.66pp；两者作用重叠（都指向"粗层分数偏高"）。
- **根因假设**：四个尺度共用 focal 目标但分辨率不同，粗层每格覆盖 2/4 帧，正样本密度更高 → logit 分布偏移；AP 全局池化把这个偏移直接变成排序错误。
- **可证伪判据**：若"学出来的"按级校准确认了 0.9/0.8 这个方向，且增益 > 手调常数（+0.72pp）→ 成立；若学出来的权重接近 1 → 不成立。
- **预期增益上限**：+0.7~1.2pp（手调已探到 +0.72）。
- **实现成本**：解码侧 0 GPU 时；若要学习则需重训。
- **结论**：**并入 P1**（质量头按尺度各一个，天然学到级间校准），不单列创新点。

### P4 训练目标（帧级二分类）与评测单位（区间 IoU）错配
- **现象**：模型优化的是"这一帧是不是假的"，指标考核的是"这个区间与 GT 的 IoU"。
- **证据**：同 P1；另外 `checkpointing score = Σ 所有 vap/var`（training.py:691），@0.95 只占 1/11，模型选择几乎不针对 @0.95。
- **根因假设**：目标函数里没有任何一项直接依赖 IoU 的**数值**（DIoU 只在正样本上、且被 `p_τ` 掩码后按正样本数平均，梯度被摊薄）。
- **可证伪判据**：若把质量目标从"IoU 软标签"换成"0/1 硬标签"，增益消失 → 说明增益来自"多一个分支"而不是"软目标"。
- **实现成本**：与 P1 同一处代码，可作 P1 的消融臂。
- **结论**：与 P1 合并为同一创新点的两个可拆分量。

### P5 标签量化（已收割，不再动）
- **证据**：整数帧标签 AP@0.95 50.60 → 连续标签 83.15（+32.55pp）；`utils/lavdf_test.json` 里 32.1% 的 GT 段在"完美拟合标签"下也达不到 IoU>0.95。
- **结论**：已在 commit 978002e 落地，作为**已兑现收益**写进论文叙事（标签轴—评测轴一致性），本轮不再改。

### P6 视频级 DFD 与 TFL 共用同一分数（副作用项）
- **现象**：视频级分数 = 最大提案分（eval.py:158）；改打分必然改 DFD AUC。
- **证据**：论文 Tab.3/4 的 99.94/99.8 AUC 来自同一分数。
- **处理**：不作为问题，但**任何打分改动都要同时报 DFD AUC**，否则是隐藏的口径变更。

## 2. 本轮不做什么（留档，避免下一轮重复）

| 排除项 | 理由（数字） | 何时可以重启 |
|---|---|---|
| 亚帧两阶段边界精炼 | 边界误差中位 0.01–0.13 帧，容许 0.85 帧；只剩 240 段近失，上限 +2~4pp | 除非 P1 把 AP@0.95 推到 >87 且瓶颈重新回到覆盖 |

## 3. 收缩结论

**只保留 1 个主问题（P1+P4 合流）：分数没有携带"这个区间有多准"的信息，而指标恰恰按它排序。**
P2/P5 进排除区，P3 作为主问题的子效应，P6 作为必须同时报告的护栏。
